# 🌿 Indonesian OUD

**Indonesian OUD** adalah website company profile sekaligus landing page yang dirancang untuk mempromosikan produk **Kayu Gaharu Premium** dari **CV. Indonesian OUD**. Website ini menampilkan informasi perusahaan, produk unggulan, galeri, keunggulan, testimoni pelanggan, serta informasi kontak untuk memudahkan calon pelanggan melakukan pemesanan.

Website dikembangkan dengan tampilan modern, responsif, dan berorientasi pada pengalaman pengguna sehingga dapat diakses dengan baik melalui desktop maupun perangkat mobile.


## ✨ Fitur

* 🏢 Company Profile CV. Indonesian OUD
* 🌿 Informasi lengkap mengenai produk Kayu Gaharu Premium
* 📦 Katalog produk berdasarkan grade
* 🖼️ Galeri produk
* ⭐ Informasi keunggulan perusahaan
* 💬 Testimoni pelanggan
* 🌍 Multi Language (Indonesia, English, العربية)
* 📱 Responsive Design
* ✨ Smooth Scroll & Scroll Animation
* 💬 Integrasi WhatsApp untuk konsultasi dan pemesanan

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS
* JavaScript (Vanilla)
* Font Awesome
* Google Fonts

## 🎯 Tujuan Project

Project ini dibuat sebagai media promosi digital untuk memperkenalkan produk Kayu Gaharu Premium dari Indonesia kepada pasar nasional maupun internasional. Fokus utama website adalah memberikan informasi produk secara profesional serta memudahkan calon pelanggan melakukan konsultasi dan pemesanan.

## 📱 Responsive

Website telah dioptimalkan agar dapat digunakan pada:

* Desktop
* Tablet
* Mobile Phone

## 🚀 Cara Menjalankan

Clone repository:

```bash
git clone https://github.com/daffarsp/indonesian-oud.git
```

Masuk ke folder project:

```bash
cd indonesian-oud
```

Kemudian buka file `index.html` menggunakan browser atau jalankan menggunakan ekstensi **Live Server** di Visual Studio Code.
